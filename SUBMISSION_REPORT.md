# QSkill Python Internship — Project Summary

**Applicant:** Atharva D. Kshirsagar

## Overview

This submission contains three Python projects selected from the QSkill Python Development Internship task list.

### Task 1 — CSV Data Analysis and Visualization

The project loads student performance data with Pandas, calculates descriptive statistics and averages, groups results by department, and creates three required visualizations using Matplotlib: a bar chart, a scatter plot, and a correlation heatmap.

### Task 5 — Sentiment Analysis Web Application

The project implements a Flask web application where a user enters text and receives a sentiment label together with TextBlob polarity and subjectivity scores.

### Task 6 — Gemini Search Assistant

The project integrates the Gemini API using the current `google-genai` SDK and Gemini Interactions API. Conversation state is continued through `previous_interaction_id`, while Google Search grounding can be enabled to answer current-information questions and expose source citations.

## Learning Outcomes

- Practical Python project organization
- Data analysis and visualization with Pandas/NumPy/Matplotlib
- Web application development with Flask
- Basic NLP sentiment analysis using TextBlob
- API integration and environment-based credential handling
- Stateful conversational AI and real-time web grounding
