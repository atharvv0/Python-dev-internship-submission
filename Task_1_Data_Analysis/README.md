# Task 1 — CSV Data Analysis and Visualization

## Objective

Load a CSV file using Pandas, perform basic analysis including the average of a selected column, and create bar charts, scatter plots, and a heatmap to identify patterns in the dataset.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib

## Dataset

`data/student_performance.csv` is a small, hand-prepared sample dataset (30 students, 3 departments) with study hours, attendance, assignment scores, and exam marks. It is illustrative, not real student data, so the very strong correlations below reflect the sample and should not be generalised.

## How to Run

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate

pip install -r requirements.txt
python analysis.py
```

The script creates charts in `output/` and writes a text summary to `output/analysis_summary.txt`.

## Analysis Performed

- Dataset shape and descriptive statistics
- Average exam score
- Maximum and minimum exam score
- Average attendance
- Average study hours
- Average score by department
- Attendance vs. exam-score relationship
- Correlation matrix heatmap

## Required Visualizations

- Bar chart: average exam score by department
- Scatter plot: study hours vs. exam score
- Heatmap: numerical feature correlations

## Results and Observations

Generated by `analysis.py` (see `output/analysis_summary.txt`):

- Average exam score is **79.43** (range 58–95); average attendance is 85.6% and average study time is 5.03 hours.
- By department: Computer **82.09**, IT **80.60**, Mechanical **74.89**. Computer leads, Mechanical trails by about 7 points.
- Study hours vs. exam score correlation is **0.99**, and attendance vs. exam score is **0.98**: students who study more and attend more score higher in this sample.
- Study hours and attendance are themselves highly correlated, so their effects cannot be separated from this data alone.
- Correlation is not causation, and with only 30 synthetic rows these figures are indicative only.

The summary file is generated by the program from the dataset rather than hard-coded.
